Princípios

O que orienta cada decisão.

Sistema antes de ferramenta.

Uma ferramenta resolve uma tarefa. Um sistema muda como a operação funciona. Entre as duas saídas, escolhemos a segunda.

IA só onde há julgamento.

Se uma regra explícita resolve, ela resolve. Modelo entra quando existe decisão a tomar, nunca para justificar o projeto.

Complexidade precisa se pagar.

Toda camada nova cobra manutenção depois. Só entra quando o ganho na operação é maior que o custo que ela cria.
